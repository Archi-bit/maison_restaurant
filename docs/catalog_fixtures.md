## Как заменить демо-данные

1. Получить утверждённый PDF/Figma и исходные изображения блюд. Сверить все восемь названий, цены, категории, краткие и полные описания, метки, рекомендуемые блюда и статус доступности.
2. Для работы с учебной БД запустить `python manage.py seed_catalog`, затем создать администратора `python manage.py createsuperuser`.
3. Открыть `/admin/`, выбрать каждое блюдо и заменить демо-цену, описание и изображение. Существующий `slug` не менять: на него могут ссылаться клиенты.
4. Проверить `/api/v1/dishes/`, `/api/v1/dishes/?featured=true` и детали каждого блюда. Проверить изображения и цены в JSON. Отдельно согласовать, какие блюда должны быть скрыты или недоступны для заказа.
5. Если нужен воспроизводимый набор **точных** seed-данных для каждого окружения, только после сверки макета заменить исходные значения в `backend/apps/catalog/management/commands/seed_catalog.py` и согласовать безопасный механизм обновления существующих данных. Простая смена `defaults` в `get_or_create` не обновит уже созданные записи.

Нельзя считать демо-данные полностью исправленными, пока эта сверка не проведена. **Не переносить локальные демо-заглушки на работающий AWS EC2.**
